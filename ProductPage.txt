I’d make the product/marketing page feel like a **quiet visual story about entering a state of focus**, rather than a conventional SaaS landing page full of cards, gradients, and buttons.

The core idea:

> **The page starts chaotic, gradually becomes quiet, introduces the product, and ends with the user entering focus.**

It should demonstrate your GSAP/ScrollTrigger/Lenis knowledge, but the animations should be mostly **large, deliberate movements** rather than hundreds of animated elements.

# Product page concept

Working narrative:

```text
CHAOS
  ↓
CHOOSE
  ↓
FOCUS
  ↓
WORK
  ↓
TOGETHER
  ↓
RESTORE
  ↓
UNDERSTAND
  ↓
FOCUS BETTER
```

The page itself becomes a story.

---

# 1. Hero — "Everything can wait."



The first viewport should be extremely minimal.

Something like:

```text
                               

                 Everything
                 can wait.

                 ┌───────────┐
                 │           │
                 │  25:00    │
                 │   FOCUS   │
                 │           │
                 └───────────┘


                         ↓ scroll
```

No navbar taking up half the screen.

Maybe:

```text
logo                         Menu
```

very subtly at the top.

### Animation

The timer slowly appears.

The background has almost imperceptible movement.

As the user scrolls:

- headline moves upward
- timer stays temporarily pinned
- surrounding content fades away
- timer becomes the visual anchor

Very little is happening, but it feels intentional.

# 17. Keep it lightweight

This is where I'd be disciplined.

I would **not** use:

- WebGL
- Three.js
- giant video backgrounds
- particle systems everywhere
- dozens of Lottie animations
- huge image backgrounds
- 3D models
- constantly running canvas effects

Instead:

### CSS

Use for:

- opacity
- transforms
- blur
- gradients
- simple transitions

### GSAP

Use for:

- scroll timelines
- pinning
- controlled movement
- scaling
- section transitions

### ScrollTrigger

Use to connect those animations to scroll.

### Lenis

Use for smooth scrolling.

### React

Only owns actual application state/UI.

The scroll animation layer should not constantly cause React state updates.

That distinction will make the page much lighter.

---

# 18. Animation philosophy

I'd use something like:

**80% subtle movement**

```text
opacity
translate
scale
blur
width
```

**15% scroll choreography**

```text
pin
transform
section transitions
```

**5% "wow" moments**

For example:

- chaos collapsing into the timer
- independent timers forming a Group
- Group disappearing and persisting
- final transition into the real app

That keeps it sophisticated rather than exhausting.

---

# 19. Visual language

I'd keep the design system very restrained:

### Typography

Large editorial headings.

Very few font weights.

Lots of whitespace.

### Shapes

Primarily:

- circles
- rounded rectangles
- thin lines

This matches the timer/bubble concept.

### Color

Mostly neutral background + the product accent.

Then user colors become the visual color system during the social sections.

For example:

```text
        🔵
   🟣       🟠
        🟢
```

The user's accent colors become part of the storytelling.

### Shadows

Very subtle.

### Borders

Thin and restrained.

## The final page should feel like this

Not:

> "Here are our 12 features."

But:

> **"This is what it feels like to move from distraction to focus."**

And as the user scrolls through that experience, they discover that the product provides the tools for each stage:

```text
DISTRACTION
     ↓
   TASKS
     ↓
   TIMER
     ↓
   SOUND
     ↓
   FOCUS
     ↓
   FRIENDS
     ↓
   GROUPS
     ↓
   HISTORY
     ↓
   UNDERSTANDING
     ↓
   FOCUS
```

That gives you a visually impressive landing page while keeping the actual implementation relatively lightweight: mostly DOM elements, CSS transforms, GSAP timelines, ScrollTrigger and Lenis rather than heavy graphical rendering. It also gives you several **real reasons to demonstrate advanced animation techniques** from your frontend knowledge rather than adding animation for its own sake.
