1. ARCHITECTURAL OVERVIEW & DESIGN PHILOSOPHY
================================================================================
The Zen Productivity Canvas is engineered as a zero-distraction "Canvas-First"
workspace where the interface itself acts as the tool. There are no cluttered
menus, ad banners, or cognitive overload. Every surface, border, and glow is
harmoniously tinted according to a 24-palette color algorithm that adapts to
both Day (Light) and Night (Dark) focus modes.

Key Architecture Principles:
- Single-Page Immersive Canvas: Zero page reloads; instantaneous state transitions.
- Multi-Agent Autonomous Physics: Member timer bubbles move independently in 
  60/120fps physics simulation avoiding collisions and center obstacles.
- Client-Side Web Audio Synthesis: Ambient background audio generated natively
  without external audio asset lag.
- Scroll-Decoupled Interaction: Column cards scroll vertically without interfering
  with horizontal board scrolling.

3. VIEW 1: SOLO IMMERSIVE FOCUS TIMER CANVAS
================================================================================
Path: `activeTab === 'timer'`
The primary workspace for deep solo work.

--------------------------------------------------------------------------------
3.1 CENTRAL PRECISION PROGRESS RING & DIGITAL CLOCK
--------------------------------------------------------------------------------
- Structure:
  * Central Disc: 414px (mobile/tablet) to 530px (desktop) circular hit-box.
  * Outer Static Track: SVG circle with stroke-width 0.75px at 22% opacity in theme hex.
  * Dynamic Progress Arc: SVG circle with stroke-width 1.5px, smooth 700ms ease-out
    transition, calculating strokeDashoffset from 0 to 301.59 based on time left.
  * Status Label: Tracking uppercase text (0.28em spacing) displaying "FOCUS",
    "REST" (during break), "PAUSED", or "DONE".
  * Main Digit Display: Extra large tabular numerals (`78px` to `100px` font size)
    rendered in light font-weight (`MM:SS`). Paused state dims digits to outline tone.
  * Target Session Dots: Row of dots representing Pomodoro rounds (default 4).
    Completed rounds scale up to 125% in active theme hex color.

- Click Logic:
  * Single Click: Debounced at 220ms. If idle/paused -> Starts timer. If running -> Pauses.
    If completed -> Starts break timer.
  * Double Click: Cancels single-click timer and completely resets timer back to
    configured focus duration (e.g. 25:00) in idle state.
  * Spacebar Shortcut: Seamlessly starts, pauses, or triggers rest phase.

- Top Task Title Header:
  * Floats cleanly above the main ring displaying the currently focused task name
    (e.g., "Architecture & Core Refactoring").

--------------------------------------------------------------------------------
3.2 AUTONOMOUS FLOATING ORBIT BUBBLES PHYSICS ENGINE
--------------------------------------------------------------------------------
- Purpose: Provides ambient social presence without communication distractions.
  Attached friends float peacefully around the main timer ring.
- Physics Simulation Algorithm (60/120fps via requestAnimationFrame):
  1. Lemniscate Guidance: Friends follow a harmonic figure-8 (infinity) mathematical curve.
  2. Live Main Timer Clearance: Dynamic repulsion boundary (`mainTimerRadius + bubbleRadius + 16px`).
     When vertical ceiling/floor space is constrained, vertical repulsion forces are
     smoothly redirected horizontally into X clearance so bubbles never get pinched.
  3. Mutual Friend-to-Friend Collision Avoidance: Live pairwise distance checks repel
     overlapping bubbles smoothly with a 450px spring force.
  4. Soft Edge Boundary Springs: Dynamic deflection prevents bubbles from touching
     the viewport edges or sidebar.
  5. Drag and Drop: Users can click and drag any friend bubble with hand/mouse to
     reposition it anywhere on the canvas. On release, the bubble resumes its orbit.
  6. Independent Timers: Each friend bubble counts down independently in real time!
     When their focus session ends, they automatically transition to "5m break" and vice versa.
  7. Interactive Controls: Hovering over a friend bubble reveals their active task tooltip
     and an 'X' button to detach them from the canvas.

--------------------------------------------------------------------------------
3.3 TASK BINDING & CONFETTI CELEBRATION
--------------------------------------------------------------------------------
- When the countdown reaches 0:00:
  * Timer state transitions to `'completed'`.
  * Increments `sessionsCompleted` count.
  * Adds focus minutes to `totalFocusMinutesToday`.
  * Fires a celebratory 60-particle confetti burst (`canvas-confetti`) tailored in
    the active theme color palette.

- Floating "+ Invite Friends" CTA (Bottom Right):
  * 44px circular floating glass button with rotating Plus icon.
  * Opens the Focus Friends Overlay to attach more accountability partners to the screen.

4. VIEW 2: ZEN TODO LIST KANBAN BOARD
================================================================================
Path: `activeTab === 'todos'`
A clean, horizontal multi-column productivity board.

--------------------------------------------------------------------------------
4.1 HORIZONTAL BOARD ARCHITECTURE & CLEAN SCROLL-BREAKING
--------------------------------------------------------------------------------
- Columns (360px - 380px wide each):
  * "Today": Active tasks scheduled for today.
  * "Upcoming": Tasks scheduled for tomorrow or future dates.
  * Custom User Columns: E.g., "Engineering", "Design", "Research", "Backlog", etc.
  * "Completed / Done": Finished tasks with strikethrough styling.
  * "+ Add Another List" Ghost Card: Quick card at far right to create new columns.

- Scroll-Breaking Logic:
  * When hovering over any column card, native vertical mouse wheel scrolling is
    captured exclusively by the task list (`.todo-list-scrollable`) so cards scroll
    smoothly without causing the horizontal board to jerk or shift.
  * When mouse is outside cards on the canvas background, vertical mouse wheel is
    translated into horizontal board panning.
  * Click-and-drag mouse panning on the board canvas is fully supported.

--------------------------------------------------------------------------------
4.2 DRAG-AND-DROP TASK REORDERING & MULTI-COLUMN ROUTING
--------------------------------------------------------------------------------
- HTML5 Drag and Drop Implementation:
  * Drag Handle: Grip icon on left of every task card.
  * Visual Feedback: Dragged card drops to 30% opacity with dashed border.
  * Drop Indicators: Glowing pulsing horizontal bar appears 'before' or 'after'
    target cards depending on top/bottom cursor position.
  * Cross-Column Drops: Dropping a task into "Completed" automatically sets `completed = true`.
    Dropping into "Today" sets `dueDate = 'Today'`. Dropping into a custom project column
    updates the task's project category dynamically.

--------------------------------------------------------------------------------
4.3 INLINE & MODAL TASK CREATION & EDITING
--------------------------------------------------------------------------------
- Inline Quick-Add in Column Header:
  * Clicking '+' on any column opens an immediate inline input. Pressing Enter adds
    the task directly to that specific list without modal interruption.
- Card Quick Actions:
  * Checkbox: Instantly toggles completion.
  * Arrow Button (Focus in Timer): Binds this specific task to the solo focus timer
    and automatically navigates the user to the Timer Canvas.
  * Trash Icon: Deletes task.
  * Card Body Click: Opens the comprehensive Task Detail Overlay.

8. GLOBAL KEYBOARD SHORTCUTS & FLOW CONTROLS
================================================================================
Shortcuts automatically suspend when typing inside text inputs/textareas.

- `Spacebar`: Start / Pause / Resume Focus Timer or trigger break phase.
- `D` / `Double Click`: Reset Timer back to default duration.
- `Cmd + K` / `Ctrl + K`: Open Global Command Palette.
- `1`: Switch to Solo Focus Timer Canvas.
- `2`: Switch to Zen Todos Board.
- `3`: Switch to Zen Focus Groups.
- `N`: Quick Add Task in Todos.
- `M`: Toggle Master Audio Mute.
- `Escape`: Close any active overlay, modal, or dropdown.

9. COMPREHENSIVE DATA MODEL & STATE FLOW
================================================================================
- `AppContext`: Global state provider managing:
  * Navigation: `activeTab` ('timer' | 'todos' | 'groups'), `overlay` (OverlayType).
  * Timer: `timerState` ('idle' | 'running' | 'paused' | 'completed'), `remainingSeconds`,
    `sessionsCompleted`, `focusDurationMinutes`, `shortBreakMinutes`, `longBreakMinutes`.
  * Tasks: List of `Task` items with CRUD actions and drag-and-drop reordering.
  * Friends & Groups: List of `Friend` items, `attachedFriendIds`, `Group` items,
    ASCII code generators, task syncing.
  * Sounds: 8 `SoundTrack` items with gain node controls and master mute.
  * Notifications: Read/dismiss actions.
  * Profile: `userAvatar` (emoji), `totalFocusMinutesToday`, `weeklyStats`.
- `ThemeContext`: Manages active `ThemeColor`, `customHex`, and `isDarkMode`.
